プライバシーポリシー

制定日：2026年10月17日

note-promo（以下「本ツール」）は、運営者 yuton が自分のアカウントだけで使う個人用ツールです。本ツールでの情報の扱いを次のとおり定めます。

1. 扱う情報

  • 運営者自身の note の公開記事（公開 RSS から読み取るタイトル・URL・本文の抜粋）
  • 運営者自身の SNS アカウントに投稿するための認証情報（アクセストークン等）
  • 投稿の記録（投稿 ID・投稿日時・URL）

運営者以外の人の個人情報は、集めず、保存しません。

2. 使い道

運営者自身の記事を紹介する投稿（文章・画像・動画）を作り、運営者自身のアカウントに投稿するためだけに使います。分析・広告・第三者への提供には使いません。

3. YouTube API サービスの利用

本ツールは YouTube API サービスを使い、運営者自身の YouTube チャンネルに動画を上げ、チャンネル名を確認します。YouTube の利用には YouTube 利用規約 が、Google による情報の扱いには Google プライバシーポリシー が適用されます。

本ツールへのアクセス許可は、Google アカウントのセキュリティ設定 からいつでも取り消せます。

4. 保存と管理

認証情報は暗号化された保管場所（GitHub Actions のシークレット）にだけ保存し、公開しません。投稿の記録は非公開のリポジトリに保存します。不要になった情報は削除します。

5. お問い合わせ

note（yuton03t） からご連絡ください。

Privacy Policy (English)

note-promo is a personal tool used only by its owner, yuton, on the owner's own accounts. It reads the public RSS feed of the owner's own note blog and creates short posts, images, and videos introducing those articles, which are posted only to the owner's own Threads, Instagram, X, and YouTube accounts after the owner approves them. It does not collect, store, analyze, or share personal data of any other person. Access tokens are stored only as encrypted GitHub Actions secrets. This tool uses YouTube API Services to upload videos to the owner's own channel; see the YouTube Terms of Service and the Google Privacy Policy. Access can be revoked at any time from Google Account permissions. Contact: note.com/yuton03t.
