# yuton-lab.github.io

note-promo（yuton が自分の note の記事を自分の SNS で紹介する個人用ツール）の公開ページです。
Google の OAuth 同意画面と YouTube API の審査で、ホームページ・プライバシーポリシー・利用規約の URL として使います。

- 持ち主: yuton-lab（個人）
- 公開先: https://yuton-lab.github.io/
- ページ: `index.html`（ホーム）、`privacy.html`（プライバシーポリシー）、`terms.html`（利用規約）
- 使い方: main に push すると GitHub Pages が 1〜2 分で反映する

ここには公開してよいページだけを置く。鍵・設定・投稿案は置かない。
